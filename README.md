# Northstar Support Deflection MVP

## What this is
A one-week MVP proving support ticket deflection for order-status and
return/refund questions via chatbot + dashboard + backend automation.

## Structure
- backend/  — Express API, data models, automation logic
- frontend/ — React app: chatbot + customer dashboard
- docs/     — API contract, test case log
